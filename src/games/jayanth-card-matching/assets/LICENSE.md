# Illustration provenance

These twelve SVG illustrations were created specifically for this game during
Phase 2, using original vector shapes. No third-party artwork, downloaded
photographs, emoji fonts or external image services are embedded in them.
They are contributed to this repository under CC0 1.0 Universal (public-domain
dedication): https://creativecommons.org/publicdomain/zero/1.0/ .

Files: dog.svg, cat.svg, rabbit.svg, bird.svg, fish.svg, butterfly.svg,
apple.svg, banana.svg, orange.svg, watermelon.svg, grapes.svg, pineapple.svg.

SVG originals are resolution independent; their intrinsic size is 640 × 640.
